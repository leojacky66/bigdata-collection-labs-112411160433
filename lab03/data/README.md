# 公开实验数据

| 文件 | 内容 |
|---|---|
| [mail_basic_public.csv](mail_basic_public.csv) | 发件人、邮箱、主题、时间 |
| [mail_pages_public.csv](mail_pages_public.csv) | 三批滚动结果，包含邮件代号与上述四列 |
| [mail_details_public.csv](mail_details_public.csv) | 三批详情结果，另附正文字数及附件字段 |

同一字段的相同原值在三张表中具有一致的代号，正文只显示字符数。基础表按采集顺序保留四列，不含邮件 ID。原始值和生成代号的密钥保存在本机课程工作区。
