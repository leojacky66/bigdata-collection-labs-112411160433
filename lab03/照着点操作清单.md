## 常见问题（选择器对不上时）

| 现象 | 处理 |
|---|---|
| 单元5采不到邮件 / 报"没有取得有效邮件ID" | 右键邮件 → 检查，确认一行邮件的 class 是不是 `.mail-list-page-item`，若不是改 `ROW_CSS` |
| 读不到发件人邮箱 | 确认悬停发件人后弹出的卡片里邮箱 class 是不是 `.cmp-account-email`，否则改 `EMAIL_CSS` |
| 正文读不到 / 是空的 | 打开一封邮件详情，检查正文容器的 class，改 `BODY_CSS` |
| 返回列表后报错 | 确认"返回"按钮的完整文字，改 `BACK_TEXT`（常见为"返回"或"收件箱"） |
| 滚动不到下一批 | 检查滚动容器 class 是否为 `.mail-list-page .ui-float-scroll-body-scrolling`，改 `SCROLL_CSS` |
